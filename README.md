# Organización Industrial · Guía de estudio

[Abrir la guía](https://danifendyk.github.io/organizacion-industrial-estudio/)

Guía completa en un HTML autónomo, con 17 bloques, 20 posibles preguntas de examen con respuestas modelo y ocho ejercicios resueltos.

Incluye índice, búsqueda sin distinción de tildes, respuestas desplegables, progreso local, tema claro/oscuro, lectura en celular e impresión.

El archivo `index.html` reúne el contenido y los controles. Podés leerlo sin conexión después de descargarlo. El progreso se guarda solo en el navegador del lector.

Las fuentes y las aclaraciones sobre las ediciones de ISO están dentro de la guía.
